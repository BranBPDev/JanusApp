# 🏛️ JanusApp

Aplicación de escritorio (Windows) que convierte la **descripción de un objeto** (un JSON, o una conversación con la IA integrada) en un **modelo 3D optimizado** con LODs, textura, apertura y esqueleto opcionales.

| 🧩 [**Objeto JSON**](docs/objeto-json.md) | El formato `janus.objeto/1`: texturas, vistas, relieves, tallado, marcas e interior |
| 🧱 [**Arquitectura**](docs/arquitectura.md) | Capas, estructura del proyecto y módulos |

| 📚 [**Referencia**](docs/referencia.md) | Constantes, `manifest.json`, glosario y limitaciones |
